## Featured Projects

### 📖 [Der Kurator — Grounded Document Q&A](https://github.com/AtharSayed/Der-Kurator)
A document-grounded RAG assistant for technical questions that prioritizes source traceability, variant-aware retrieval, and abstaining when the evidence is insufficient.

- **97.1% grounded sentence rate** and **99.1% average faithfulness** in the project's published evaluation results.
- Multi-format ingestion for PDF, DOCX, PPTX, and TXT.
- Structure-aware chunking, FAISS retrieval, Sentence Transformers, answer gating, and retrieval tests.

`Python` `RAG` `FAISS` `Sentence Transformers` `Streamlit`

### 🎥 [IntelliTube](https://github.com/AtharSayed/Intellitube)
A privacy-first YouTube analysis system that turns video content and comments into searchable, structured knowledge using locally run open-source models.

- Speech transcription, transcript correction, and long-form summarization.
- RAG-based Q&A over video transcripts.
- Comment sentiment, intent, and emotion analysis with an interactive analytics dashboard.

`Faster-Whisper` `Mistral` `FAISS` `Hugging Face` `Streamlit` `Gradio` `Flask` `MongoDB`

### 🛡️ [Vigilix — Intrusion Detection & Monitoring](https://github.com/AtharSayed/Vigilix)
A streaming network-intrusion detection pipeline combining machine learning inference with operational monitoring and dashboards.

- Kafka-based data ingestion and streaming inference.
- XGBoost, Random Forest, and Isolation Forest model workflows.
- Docker Compose deployment with Prometheus metrics and Grafana dashboards.

`Python` `Kafka` `XGBoost` `Isolation Forest` `Docker` `Prometheus` `Grafana`
